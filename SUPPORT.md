# Support

- **Questions and usage help:** open a GitHub Discussion or an issue using the question label at https://github.com/shahvatsalofficial/contribsutra-ai/issues
- **Bugs:** use the bug report template; include `contribsutra --version`, your OS, Node version and the exact command. Remove tokens and private paths first.
- **Security problems:** do **not** open a public issue. See [SECURITY.md](SECURITY.md).
- **Response times:** this is a volunteer project. No SLA is offered or implied.
