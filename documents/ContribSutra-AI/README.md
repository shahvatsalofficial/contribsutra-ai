# ContribSutra AI — documents

Complete documentation set for **ContribSutra AI 0.2.0** (technical, functional, architecture, executive, user guide, security, evidence, test report, legal, roadmap, glossary, assurance).

- Start: `html/index.html` (open in a browser; self-contained, responsive, light/dark, printable)
- Markdown sources: `md/` (with placeholders) and `md-rendered/` (numbers filled from the recorded run)
- Proof: `test-results/` (TAP log, fuzz, environment) · Samples: `samples/` (real audit report in MD/HTML/JSON, CLI transcripts)
- Rebuild: `node build.mjs` after `npm run proof` and `npm run audit` in `../../ContribSutra-AI`

Project: https://github.com/shahvatsalofficial/contribsutra-ai
