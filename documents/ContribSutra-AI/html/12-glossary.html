Glossary

TermMeaning
Agent skill (SKILL.md)A text file with instructions an AI coding assistant may follow. It is not a program and cannot enforce anything
AGENTS.mdA convention for repository-level instructions to coding agents
Audit packThe HTML, Markdown and JSON output of contribsutra audit plus SHA256SUMS.txt
Assurance checkOne adversarial test run by the audit against the real code, with expected and observed results
CLAContributor License Agreement: a legal agreement some projects require before merging
DCODeveloper Certificate of Origin: a Signed-off-by line on commits
CODEOWNERSA file mapping paths to the people who must review them
Decline ruleA condition that makes an issue ineligible (closed, assigned, locked, security-like, injected)
Documented commandA command quoted from a README or CONTRIBUTING code block. Never executed
Evidence channelOne of verified, user-reported, inferred/recommended, not-run/unknown
Evidence tierA label in the audit saying how strong a piece of evidence is
FixtureA small synthetic repository or issue file used by tests
Good first issueA label some maintainers use for beginner-friendly work. A label is not consent
HeuristicA rule of thumb that can be wrong. Reported as inferred
Instruction injectionText that tries to give commands to an AI agent reading it
LifecycleThe ordered states from discovered to submitted_by_human. The tool stops at planning
Negative controlA test input that must be flagged, proving the checks can fail
Policy signalA text match about DCO, CLA, AI policy and similar, quoted with file:line
PR packetThe pr-check output: statements, claims, channels, checklist and draft description
SealSHA-256 over the JSON of a report. Detects accidental change. Not a signature
SnapshotA JSON file of issues that you exported. It is a photograph, not live data
Skipped testA test the host could not run. Not a pass
Trust boundaryThe line between what the tool controls and untrusted content
Untrusted dataEverything read from a repository or issue
VerdictREADY_FOR_HUMAN_REVIEW, GAPS_FOUND or ASSURANCE_FAILED. Never "approved"
