## What ships
- **No third-party code:** zero runtime and zero development npm dependencies; Node.js built-ins only.
- **No datasets or model weights.** Fixtures are small synthetic files written for tests. Nothing is downloaded at install or run time.
- **No external resources in reports:** inline CSS only; no fonts, scripts, trackers or CDN calls.

## Privacy
No telemetry. No network access in the CLI (the optional `serve` binds `127.0.0.1`). Reports contain file paths relative to the inspected repository, hashes, and redacted short excerpts of policy text. Issue bodies are scanned for risk but never copied into reports. Redaction is heuristic and cannot prove that nothing sensitive remains: review a report before sharing it.

## Third-party content you analyze
ContribSutra reads files you point it at. It records hashes and short quoted lines with line numbers, not full copies. Respect the license of any repository you inspect and the terms of the service you exported issues from. Exporting an issue snapshot with your own GitHub account is subject to GitHub's Terms and API rules; ContribSutra does not fetch anything itself.

## Maintainers and contributors
ContribSutra is designed to reduce review burden: it declines unwanted work, warns about CLA/DCO and AI-contribution policies, and never submits anything. A project may forbid AI-generated pull requests; the tool surfaces such text when present and leaves the decision to a person. It does not bypass rate limits, CAPTCHAs, branch protections or consent.

## Claims discipline
Docs and reports must not state that a contribution will be accepted, that a test passed unless captured output exists, that a project is "safe" or "secure", or that an IDE natively runs the skills before that was observed. Adoption, satisfaction and acceptance rates are **not measured**, so none are claimed. There are no testimonials.

## Safety-critical and regulated use
The tool is analysis-only and read-only. It is not a substitute for maintainer judgment, security review or legal review.

## Independent-audit stance
Every number in public docs is regenerated by `npm run proof` and tied to raw logs in `docs/proof/`. The audit report is a reproducible self-assessment; it is not third-party certification. Anything not run is labelled so.
