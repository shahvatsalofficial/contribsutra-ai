# Contributing to ContribSutra AI

Thank you for helping make open source welcoming. Start with `README.md`, then run `npm test` and `npm run demo`. Prefer small, scoped fixes with tests. File an issue or discuss with maintainers before major changes. Never create bulk automated pull requests or use invented test evidence. Explain AI-assisted changes and keep a person accountable. Follow `CODE_OF_CONDUCT.md`. Security disclosures should follow `SECURITY.md` privately.
